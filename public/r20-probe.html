Roll20 Drag Probe

Drag a compendium entry from a Roll20 tab and drop it below. Everything the drag carries is dumped verbatim — copy the result and paste it back to Claude.

What to capture

  1. This page: open the Roll20 compendium — both the in-VTT sidebar tab (pop it out if you can) and the standalone site roll20.net/compendium/dnd5e — and drag one spell, one item, and one monster onto the zone above. Try from both sources; they may carry different data.
  2. Network: in the VTT with DevTools → Network open (filter getPages), drag a spell from the compendium tab onto an open character sheet. Copy the full request URL and the full JSON response. Repeat for an item.
  3. Element: right-click a compendium entry in the VTT sidebar → Inspect → copy the element's outerHTML.
  4. Sheet: note which character sheet the campaign uses (Settings → Game Settings), e.g. "D&D 5e by Roll20" vs the 2014/OGL sheet.
